# محصول، محدوده و صفحات

## تعریف محصول

کتابخانه‌ای فارسی برای نوجوانان، جوانان و دیگر علاقه‌مندان مطالب آموزشی و دینی؛ با تمرکز بر یافتن نقطه شروع، مطالعه آرام، دنبال‌کردن مجموعه و بازگشت به محل قبلی. مدیر محتوا کاربری غیرتخصصی است و نباید برای انتشار متن به Git یا پایگاه داده مراجعه کند.

موفقیت نسخه اول با آزمون کاربری سنجیده می‌شود: بازدیدکننده جدید در کمتر از ۳۰ ثانیه مسیر شروع را پیدا کند؛ خواننده بتواند در حداکثر دو اقدام به مطلب نیمه‌تمام برگردد؛ مدیر بتواند یک رکورد را بررسی و بدون کمک توسعه‌دهنده منتشر کند. این‌ها اهداف آزمون‌اند، نه نتایج اندازه‌گیری‌شده.

## سفرهای اصلی

1. ورود از صفحه اصلی یا موتور جست‌وجو → شناخت مجموعه → «شروع مطالعه» → متن → «خواندم» → قسمت بعد.
2. بازگشت → کارت «ادامه مطالعه» → بازیابی بخش قبلی → مشاهده پیشرفت مجموعه.
3. جست‌وجوی موضوع → فیلتر مجموعه/موضوع → انتخاب نتیجه → ذخیره نشانک؛ ثبت‌نام اختیاری برای همگام‌سازی.
4. ورود حساب → مشاهده تاریخچه، نشانک‌ها و دیدگاه‌ها → ادامه مطالعه روی دستگاه دیگر.
5. ورود مدیر → واردسازی آزمایشی → بررسی اصل و تکرارها → تنظیم عنوان و ترتیب → پیش‌نمایش → انتشار.

## محدوده نخستین انتشار

تمام سه مجموعه اصلی، ظرفیت مجموعه چهارم «فلسفه اشک»، مطالب مستقلِ تأییدشده، جست‌وجو و فیلتر، تنظیم فونت و پوسته، پیشرفت و نشانک مهمان/عضو، ثبت‌نام ایمیل و گذرواژه، بازیابی دسترسی، داشبورد و مدیریت پایه در محدوده هستند. همه رکوردها وارد صف بررسی می‌شوند؛ انتشار عمومی تنها برای موارد تأییدشده است.

دیدگاه‌ها متنی، با یک سطح پاسخ و تأیید پیش از نمایش هستند. لایک، پیام خصوصی، اعلان زنده، پیوست دیدگاه، شبکه اجتماعی و پاسخ‌های تودرتو در نسخه اول نیستند. حساب اجباری، پرداخت، اشتراک، موتور پیشنهاد هوشمند، انتشار خودکار، ویرایش هوش مصنوعی و راستی‌آزمایی خودکار محتوا نیز در محدوده نیستند.

بعداً و بر اساس نیاز واقعی: PWA و مطالعه آفلاین، صوت، دنبال‌کردن مجموعه و اعلان اختیاری، جست‌وجوی پیشرفته، گردش تأیید چندنفره، ورود پیامکی و تقویم انتشار. هیچ‌کدام پیش‌نیاز نسخه اول نیست.

## نقشه صفحات و مالکیت

| مسیر | مالک | محتوای صفحه و حالت‌های مهم |
|---|---|---|
| `/` | Astro | معرفی کوتاه، شروع پیشنهادی تحریریه، سه مجموعه اصلی، ادامه مطالعه شخصی پس از بارگذاری |
| `/collections` | Astro | فهرست مجموعه‌ها و توضیح مسیرها |
| `/collections/[slug]` | Astro | معرفی، شروع پیشنهادی، فهرست مرتب، وضعیت هر قسمت، توضیح ناقص‌بودن آرشیو |
| `/posts/[slug]` | Astro | متن، زمان مطالعه، ابزار خواندن، قبلی/بعدی، مرتبط‌ها و دیدگاه‌ها |
| `/topics` و `/topics/[slug]` | Astro | موضوعات و مطالب منتشرشده مرتبط |
| `/search?q=&collection=&topic=` | Astro | جست‌وجوی عمومی با صفحه‌بندی؛ وضعیت خواندن در جزیره شخصی و خارج از URL اشتراکی |
| `/about`، `/privacy`، `/comment-policy` | Astro | درباره، حریم خصوصی و قواعد دیدگاه |
| `/404` | Astro | مسیر جایگزین و جست‌وجو؛ بدون افشای عنوان پیش‌نویس |
| `/app/auth/sign-up`، `/sign-in`، `/forgot-password` | Next.js | ثبت‌نام، ورود، درخواست بازیابی؛ پیام یکسان برای ایمیل ناشناخته |
| `/app/auth/callback`، `/app/auth/reset-password` | Next.js | تأیید ایمیل، بازگشت مجاز، خطای لینک منقضی و انتخاب گذرواژه جدید |
| `/app/account` | Next.js | خلاصه پیشرفت و ادامه مطالعه |
| `/app/account/history`، `/bookmarks`، `/comments`، `/profile` | Next.js | فهرست‌های خصوصی، حذف نشانک، وضعیت دیدگاه و نام نمایشی |
| `/app/admin` | Next.js | صف کار، خطاهای واردسازی، آمار تجمیعی |
| `/app/admin/posts`، `/posts/new`، `/posts/[id]` | Next.js | فهرست، ایجاد، ویرایش، نسخه‌ها، پیش‌نمایش و انتشار |
| `/app/admin/collections`، `/topics`، `/media` | Next.js | مدیریت ترتیب با دکمه و کشیدن، موضوعات، تصویر و متن جایگزین |
| `/app/admin/imports`، `/imports/[id]` | Next.js | بارگذاری، dry-run، تکرارها، تعارض‌ها، دلایل پذیرش/رد |
| `/app/admin/comments`، `/reports`، `/users` | Next.js | تعدیل دیدگاه، گزارش‌ها و نقش‌های کاربران |
| `/app/api/*` | Next.js | قرارداد داده؛ صفحه قابل ایندکس نیست |

در ردیف‌هایی که چند پسوند آمده، همه زیر پیشوند ابتدای همان ردیف‌اند. خروج از حساب یک درخواست POST است. صفحات حساب، مدیریت و پیش‌نمایش `noindex` و `no-store` دارند.

تمام صفحه‌های داده‌محور به حالت بارگذاری، خالی، خطا و بازیابی نیاز دارند. ذخیره موفق باید قابل مشاهده باشد؛ شکست ذخیره نشانک یا پیشرفت نباید با موفقیت ظاهری پنهان شود. در نبود JavaScript، متن و ناوبری عمومی خواندنی می‌مانند.
