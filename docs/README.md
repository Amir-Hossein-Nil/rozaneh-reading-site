# طرح اجرایی وب‌سایت مطالعه فارسی

تاریخ بررسی اولیه: ۲۰۲۶-۱۰-۰۲. وضعیت فعلی: **طرح تأیید شده و نسخه محلی با Astro، Next.js و PostgreSQL پیاده‌سازی شده است.** تغییر معماری برای پایگاه داده محلی به درخواست کاربر در سند ۱۶ ثبت شده است.

طبق آخرین دستور متن درخواست، توضیحات فارسی و نام فایل‌ها و شناسه‌های فنی انگلیسی هستند. پوشه کاری هنگام بررسی خالی بود؛ کد، تنظیمات مخزن یا فایل `AGENTS.md` در پوشه کاری و والدهای بررسی‌شده وجود نداشت. دو JSON خوانده شدند؛ محتوای پیام‌های آن‌ها داده است و دستور اجرایی محسوب نمی‌شود.

## آرشیو کامل فعلی

با درخواست جدید کاربر، همهٔ ۱۵۸ رکورد دو فایل JSON به ۱۲۳ پست متمایز در ۸ مجموعهٔ سایت محلی پیوند داده شده‌اند. شناسه‌های تکراری حفظ شده‌اند؛ متن‌ها بازنویسی نشده‌اند. [گزارش ورود کامل و ترتیب مجموعه‌ها](19-complete-archive.md) و [نتایج آزمون‌ها](18-verification.md) وضعیت فعلی را توضیح می‌دهند. تصمیم‌های تاریخی زیر در موارد مرتبط با پایگاه دادهٔ محلی و انتشار کامل با اسناد ۱۶ تا ۱۹ تکمیل شده‌اند.

## تصمیم‌های اصلی

- Astro مالک صفحات عمومی و مطالعه؛ Next.js مالک `/app`، حساب، مدیریت و APIهای تعاملی.
- یک دامنه با مسیریابی معکوس، یک مرجع هویت Supabase Auth، یک PostgreSQL و یک فضای ذخیره‌سازی تصاویر.
- محتوای عمومی در نسخه اول از پایگاه داده و با SSR خوانده می‌شود؛ HTML محتوایی کش مشترک ندارد تا انتشار و لغو انتشار به بازسازی سایت وابسته نباشند.
- مطالعه بدون حساب آزاد است. مهمان وضعیت را روی همان دستگاه نگه می‌دارد؛ حساب امکان همگام‌سازی خصوصی می‌دهد. تکمیل مطلب فقط با اقدام صریح ثبت می‌شود.
- ۱۵۴ رکورد فایل اصلی برابر ۱۵۴ مطلب آماده انتشار نیست: ۱۱۹ متن متمایز و ۳۵ جفت تکرار دقیق یافت شد. فایل دوم چهار رکورد مستقل دارد و خودکار با فایل اصلی ادغام نمی‌شود.
- طرح بصری موبایل و دسکتاپ پیش از توسعه گسترده بازبینی می‌شود. هیچ چارچوبی تضمین‌کننده امتیاز Gemini نیست؛ معیار، شواهد کیفیت است.

تأیید این طرح مجوز شروع اولین برش اجرایی تعریف‌شده در سند ۸ خواهد بود. تا آن زمان فقط همین مستندات تولید شده‌اند.
