## Homepage

Use case: ui-mockup. Create one exceptionally polished, realistic desktop website homepage screenshot for a Persian RTL educational and religious informational reading library. This is a visual design proposal, not a promotional poster. Landscape screenshot approx 1536x1024, straight-on flat interface, no device frame. Title is temporary: "مطالب آموزشی و دینی". Design goal: many short information topics are visible, compact title rows rather than enormous cards. Top narrow navigation on right title, then "خانه", "مجموعه‌ها", "موضوعات", search and subtle account button. Short welcoming heading "موضوعی برای امروز پیدا کنید" and wide search field "جست‌وجو در مطالب". A row of four small collection tiles named exactly "اعتقادات روشن", "ردپای حضرت", "زندگی با امیردل‌ها", "فلسفه اشک", differentiated by subdued green, slate blue, terracotta, plum accents, with simple line book motifs. Underneath topic filter chips "همه", "اخلاق", "خودشناسی", "دعا", "انتظار", "کتاب". Main column has clean divided article rows, each two lines maximum with small series badge and bookmark icon. Use exact source titles: "تقوا؛ هنرِ مهارِ غریزه در عصرِ مدرن", "مدرسه اجباری زندگی", "دفتر دعای خودمانی", "تقوا؛ محدودیت یا مراقبت؟", "چرا هنوز برای حسین(ع) گریه می‌کنیم؟", "نحوه‌ی پرسش‌گری", "عقل، حجت خداست!", "برنده کسی است که صبور باشد". Show 7–8 clearly readable entries. If using excerpt on the prayer entry use only "در همه‌ فرهنگ‌ها دعا جاری‌ست." Do not invent religious quotations or publication dates or total counts. Narrow right sidebar labelled "مجموعه‌ها" with four collection names and simple topic links, understated starting point button "شروع مطالعه". A small understated continue-reading strip is okay, labelled "ادامه مطالعه". Airy gutters, strong hierarchy, minimal rounding 8px, precise 1px dividers. Sharp legible typography. Looks like a production editorial knowledge website with information density and beautiful reading comfort.
